# Earth Texture Credits

These public-domain / freely-licensed Earth textures are bundled locally:

- `earth-day.jpg` <- https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
- `earth-night.png` <- https://threejs.org/examples/textures/planets/earth_lights_2048.png
- `earth-clouds.png` <- https://threejs.org/examples/textures/planets/earth_clouds_1024.png

All three are NASA Blue Marble / Earth-at-Night derived imagery distributed with
the three.js examples (MIT-licensed project). NASA imagery is public domain.
Source network was unreachable for larger NASA/Solar System Scope originals,
so the bundled set uses the 2048px / 1024px variants.
